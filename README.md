# tetris_game

Tetris was invented in June 1984 by Alexey Pajitnov, a Soviet software
engineer working at the Academy of Sciences in Moscow, USSR. The original
ran on an Electronika 60, a terminal with no graphics capability at all —
the tetrominoes were drawn out of pairs of square brackets.

In this project I tried to recreate that authentic look: bracket-drawn
pieces, monochrome phosphor text, and the soft glow and scanlines of an
old CRT.
